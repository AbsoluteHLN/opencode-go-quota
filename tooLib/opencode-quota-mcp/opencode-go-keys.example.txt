# opencode Go 多 key 名册（工具版本 v1.1.0+）
# ══════════════════════════════════════════════════════════
# 口径：一人一个 key。每人持有各自独立订阅的 opencode Go API key，
#       本工具逐把查询官方接口、按人一行输出（本地归因，非官方账单）。
#
# ── 每行写法（二选一）──
#   标签|key      推荐。标签显示在表格「人员」列与备注前缀。
#   key           纯 key，无标签时「人员」列显示 key 掩码。
#
# ── 格式规则 ──
#   - | 是唯一分隔符；一行出现两个及以上 | 会报错退出（提示 文件:行号）。
#   - 标签与 key 内不能含空白（空格/Tab），否则报错退出（提示行号）。
#   - 行首 # 开头 = 整行注释；空行忽略；行内出现 " #" 时其后内容当作注释截断。
#   - 自动去除 UTF-8 BOM 与两侧成对引号。
#   - 相同 key 只查一次：保留首个标签，其余条目出「去重」备注。
#   - 去重后只剩 1 把 key → 走单 key 模式（与 v1.0.0 输出完全一致）。
#   - ≥2 把不同 key → 多 key 模式：顺序逐把查询、按人一行、单把失败不影响其他。
#
# ── 用法（二选一）──
#   1) 自动发现：把本文件放在脚本同目录（即 temp/opencode-go-keys.txt），直接运行脚本即可。
#   2) 显式指定：node opencode-go-quota.mjs --keys-file <名册路径>
#      --keys-file 可重复传入多个名册文件，全部合并后再去重。
#
# ── key 从哪来 ──
#   请各人登录自己的 opencode 控制台自行创建 API key，自行填进本文件
#   （或自己保管、运行时用 --key 传入）。不要共享 key、不要把 key 贴进聊天。
#
# ── 示例（全部是占位 key，删掉行首的 "# " 并换成真实 key 才生效）──
# 张三|oc_replace_me_with_real_key_0001
# 李四|oc_replace_me_with_real_key_0002
# 王五|oc_replace_me_with_real_key_0003
# oc_replace_me_with_real_key_0004
